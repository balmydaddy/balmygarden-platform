# 비용 0으로 "항시 켜진 개인 서버"를 굴리는 구성

> CEO 지시 2026-09-06 — "항시 전원 켜있으며 비용 지출 없이 개인 서버처럼 운영할 수
> 있는 방법이 있다면 운영하겠다. 필요로 하는 API를 영구적으로 무료 사용 가능하면
> 지장없을 텐데 토큰이나 사용량이 제한적이라 대부분이 지연되고 있다."

---

## 0. 결론 먼저

**항시 켜진 무료 서버는 이미 셋 돌고 있다. 새로 살 것이 없다.** 라즈베리파이를 접은
판단은 결과적으로 맞았다 — 사려던 것이 이미 무료로 있었다.

**그런데 대표님이 겪는 "지연"은 서버 문제가 아니다.** 서버를 하나 더 붙여도 안 풀린다.
병목은 기기가 아니라 **모델 사용량**이고, 그건 무료 호스트로 못 늘린다.

그래서 이 문서의 실질 내용은 "무료 서버를 어떻게 구하나"가 아니라 **"LLM이 필요 없는
일을 LLM에서 어떻게 빼내나"**다. 그게 지연을 실제로 줄이는 유일한 무료 수단이다.

## 1. 지금 이미 돌고 있는 것

| 무엇 | 어디 | 주기 | 비용 |
|---|---|---|---|
| 플랫폼 배포 + 일일 cron | Vercel (`vercel.json` → `/api/cron`) | 매일 00:00 UTC | 0 |
| Unity 컴파일 확인 | GitHub Actions (`unity-ci.yml`) | push마다 | 0 (아래 2절 단서) |
| LOD 자동개발 루프 | 이 클라우드 세션 정기 트리거 | 8시간마다 | 구독 안 (Claude Pro) |
| 네이버 블로그 초안 3건 | 같은 트리거 | 매일 | 구독 안 |

**모바일·로컬 동시 운영도 이미 된다.** 이 세션은 claude.ai/code에 있어 폰에서든 PC에서든
같은 세션에 붙고, Vercel 배포물은 URL이라 기기를 안 가린다. 집 PC를 켜둘 필요가 없다.

---

## 2. 무료 한도는 "무한"이 아니다 — 하나가 이미 위험했다

GitHub Actions는 **비공개 저장소에서 월 2,000분**이 무료다. 공개 저장소는 무제한이다.

| 저장소 | 공개 여부 | Actions 분 |
|---|---|---|
| `lord-of-dark` | **비공개** | 한도 차감 |
| `balmydaddy-safety` | **비공개** | 한도 차감 |
| `balmygarden-platform` | **공개** | 무제한 |
| `balmydaddy-receipt` | **공개** | 무제한 |

`lord-of-dark`의 Unity CI는 1회에 약 10분이다. 최근 3일간 26회가 돌았으니 약 260분,
그 속도면 **월 2,600분으로 한도를 넘는다.** 그리고 그 26회의 절반가량이 `docs/`만 바꾼
커밋이었다 — 자동개발 사이클이 코드 커밋 하나에 문서 커밋을 한둘 붙이는 구조라서다.

넘으면 **과금이 아니라 CI가 멈춘다**(지출 한도 기본값 0). COST-01 관점에서는 다행이지만,
멈추면 LOD-DEV-03 게이트의 "CI 그린" 조건을 만족시킬 수 없어 자동개발 루프가 통째로
막힌다. 그게 실제 위험이었다.

**2026-09-06 조치 완료** — `unity-ci.yml`에 `paths-ignore`를 넣어 `docs/**`·`tools/**`·
`**/*.md`만 바뀐 커밋은 건너뛴다. 바뀐 파일이 **전부** 그 목록일 때만 건너뛰므로 C#·JSON·
씬이 한 줄이라도 바뀌면 그대로 돈다. 컴파일 확인이 필요한 커밋은 하나도 안 빠진다.

---

## 3. 왜 새 서버가 지연을 안 풀어주나

지금 자동화가 하는 일은 대부분 **판단**이다 — 백로그에서 무엇을 고를지, diff가 통과인지,
초안이 기준에 맞는지. 이건 전부 모델이 한다.

무료 서버를 하나 더 붙이면 **모델을 부를 자리가 하나 더 생길 뿐** 부를 수 있는 양은
그대로다. 병목은 Claude Pro의 5시간 롤링 한도와 우리 스스로 정한 USAGE-05(5% 유보)다.
기기를 늘려도 이 둘은 안 늘어난다.

**라즈베리파이를 샀어도 같았다.** 전기요금과 기기값을 쓰고 나서도 지연은 그대로였을
것이다. 접은 게 맞았다.

---

## 4. "영구 무료 API"는 없다

무료 등급은 제공사가 언제든 바꾼다. 영구를 약속하는 곳은 없고, 약속해도 지킬 의무가 없다.
그래서 COST-01이 요구하는 건 "영구 무료"가 아니라 **"한도를 넘겨도 과금이 아니라 거절되는
구성"**이다. 이건 이미 지키고 있다.

무료 LLM API(Groq·Gemini 무료 등급 등)를 붙이면 COST-01은 통과한다. 그런데 셋이 걸린다.

| 걸리는 것 | 왜 |
|---|---|
| TOOL-01 1번 | 품질 게이트 경로에 모델 대체를 넣지 않는다. AEGIS 95점은 채점자가 고정돼야 뜻이 있다 |
| TOOL-01 2번 | 무료 등급은 입력을 학습에 쓰는 경우가 흔하다. `lord-of-dark`는 비공개다 |
| 자동 과금 전환 | 결제 수단이 등록돼 있으면 무료 등급 초과가 거절이 아니라 과금이 된다 |

**쓸 수 있는 자리가 없지는 않다.** 우리 모델 라우팅의 "Haiku 60% — 분류·요약·형식 검증"에
해당하는 기계적인 일이라면, 비공개 저장소 내용을 안 넣고 게이트에 안 쓰는 조건으로 검토
가능하다. 다만 그건 **지금 지연의 주범이 아니다** — 지연은 판단 작업에서 난다.

## 5. 실제로 지연을 줄이는 방법 — LLM에서 빼내기

무료로 늘릴 수 있는 건 모델 사용량이 아니라 **모델을 안 써도 되는 일의 비중**이다.

이미 그렇게 한 것들:

| 일 | 전에는 | 지금 |
|---|---|---|
| 밸런스 수치 산출 | 손계산(틀린 전례 여러 번) | `tools/calc_block_uptime.py` — 스크립트, LLM 0회 |
| 한글 문자 집합 추출 | — | `tools/extract_korean_charset.py` — 스크립트 |
| 블로그 초안 자체 점검 | 눈으로 훑기 | 파이썬 — 분량·금지 접속사·표 깨짐·400자 구간 |
| 영상 판독 | 불가 | ffmpeg 프레임 추출 후 판독(2026-09-06) |

**아직 안 뺀 것 — 다음에 뺄 후보:**

1. **저장소 상태 집계.** §10 미해결 건수, 최근 커밋, CI 결과는 전부 기계가 셀 수 있다.
   지금은 매 사이클 모델이 읽어서 센다.
2. **문서 형식 검증.** 표 파이프 개수, 이스케이프 누락, 링크 유효성. 이번 주에 표 깨짐이
   실제로 한 번 났다.
3. **커밋 메시지 규칙 확인.** 서명 줄 누락 같은 것.

이 셋은 GitHub Actions cron으로 옮기면 항시 켜진 무료 서버가 대신 돈다. 다만 `lord-of-dark`는
비공개라 분을 먹으므로, **공개 저장소인 `balmygarden-platform`에 두고 필요한 것만 읽어오는
구성**이 맞다. 그러려면 비공개 저장소 접근 토큰이 필요하고 그건 CEO가 넣어야 한다.

## 7. CEO 확인이 필요한 것

**하나. `balmygarden-platform`이 공개 저장소다.**

Actions 분이 무제한이라는 이점은 여기서 온다. 그런데 이 저장소의 `CLAUDE.md`에는
CEO 실명·직장명·4트랙 사업 계획·크몽 상품 번호가 들어 있다. API 키는 없지만
(`.env.local` 커밋 금지를 지켜왔다) **사업 정보와 개인 정보는 그대로 공개돼 있다.**

비공개로 돌리면 그 노출은 사라지고, 대신 Actions 분이 한도 차감으로 바뀐다. 지금 이
저장소는 CI를 안 돌리므로 당장 차감될 것은 없다.

이건 비용 문제가 아니라 노출 문제라 CEO가 정할 사항이다.

**둘. GitHub Billing 실제 값 확인.**

2절의 분 계산은 run 번호 증가분과 1회 소요시간에서 추정한 것이다. 실제 잔여 분과 지출
한도 설정값은 조회 권한이 없어 못 봤다. GitHub 설정 → Billing에서 확인하면 좋다.
**지출 한도가 0이 아니면 한도 초과 시 과금된다** — 0인지 확인이 필요하다.
