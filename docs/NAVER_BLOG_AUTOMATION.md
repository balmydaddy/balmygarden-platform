# 네이버 블로그 자동 발행 — 조사 결과 (2026-08-22)

> CEO 지시: "네이버 블로그 자동화에 대해 더 조사해서 진행될 수 있게 해라"
> 조사자: CONDUCTOR / SCOUT

---

## 결론 먼저

**공식 API로는 불가능하다. 우회 자동화는 기술적으로는 되지만, 이 계정으로는
권하지 않는다.** 지금은 복붙 산출물(자동 생성 → CEO가 붙여넣기)이 최선이고,
그건 이미 구현했다(`/api/cron` 네이버 파이프라인 → Notion 일 3건).

---

## 1. 공식 API — 없다 (확인 완료)

네이버는 **2020년 5월 6일자로 블로그 '글쓰기 API'를 종료**했다. 워드·구글독스
같은 외부 도구에서 네이버 로그인 없이 바로 글을 올리던 기능인데, 광고성 글
대량 게재에 악용되면서 서비스 10년 만에 닫았다.

**종료 사유 자체가 "자동 대량 포스팅 차단"이다.** 즉 다시 열릴 가능성이 낮고,
같은 목적의 우회 수단은 네이버가 잡으려는 대상 그 자체다.

현재 네이버 개발자센터가 제공하는 블로그 관련 API는 **검색(읽기)** 뿐이다 —
`search/blog`로 남의 글을 조회할 수는 있어도 내 글을 쓸 수는 없다.
(우리는 이미 SCOUT 뉴스 수집에 검색 API 경로를 쓰고 있다.)

---

## 2. 우회 자동화 — 되지만 위험이 크다

| 방식 | 가능 여부 | 위험 |
|---|---|---|
| Selenium·Playwright 브라우저 자동화 | 기술적으로 가능 | **저품질 판정 위험 높음.** 이용약관 위반 소지 |
| 제3자 자동 포스팅 도구(마케팅 툴) | 가능 | 위와 동일 — 내부적으로 브라우저 자동화 |
| 모바일 앱 API 리버싱 | 가능 | 약관 위반 + 계정 정지 위험 |

### 왜 위험이 큰가

네이버 **저품질은 글 단위가 아니라 블로그 단위**로 걸린다. 한 번 걸리면 그
블로그의 모든 글이 검색 3페이지 이후(21번째~)로 밀려 사실상 유입이 끊긴다.

저품질 분류 사유로 **"자동화·어뷰징 등 비정상적인 방법으로 글을 올리는 경우"**가
명시적으로 꼽힌다. 게다가 네이버는 2026년 2월 검색 알고리즘 개편을 공지하며
**AI 자동 생성 콘텐츠와 실경험 없는 광고성 글을 강하게 걸러내겠다**고 밝혔고,
3월 초 실제로 다수 블로그가 저품질로 분류되며 유입이 급감한 사례가 보고됐다.

우리가 올리려는 글은 (a) AI 생성이고 (b) 자동 게시이며 (c) 홍보 목적이다 —
네이버가 지목한 세 조건에 정확히 겹친다. **얻는 것은 손이 편해지는 것뿐인데,
잃는 것은 블로그 계정 전체의 검색 노출이다.** 비대칭이 심하다.

---

## 3. 그래서 지금 하는 것 — 복붙 산출물 (구현 완료)

`src/app/api/cron/route.ts`가 매일 **네이버 전용 초안 3건**을 생성해 Notion에
붙여넣기 가능한 형태로 저장한다.

- 주제 3개는 트랙별로 나눈다: **안전관리 / 음악 / 트렌드**
- Blogger 글을 복사하지 않는다 — MULTI-01(채널별 재구성)에 따라 네이버용으로
  따로 쓴다. 분량·구성·톤이 다르다
- BLOG-01(본문 구성 기준)을 적용해 이미지 자리와 캡션·대체텍스트·생성 프롬프트를
  본문 안에 표시한다. CEO는 `[[이미지]]` 표시가 나오는 자리에 사진을 넣으면 된다
- AEGIS 법무 게이트를 통과한 것만 저장한다

**CEO가 하는 일**: Notion 페이지에서 제목·본문을 복사 → 네이버 에디터에 붙여넣기
→ `[[이미지]]` 자리에 사진 삽입 → 발행. 하루 3건.

---

## 4. 자동화로 넘어갈 조건

아래 중 하나가 충족되면 재검토한다. 그전까지는 복붙을 유지한다.

1. **네이버가 공식 발행 API를 다시 연다** — 가능성 낮지만 공식 경로가 생기면 즉시 전환
2. **블로그가 충분히 성장해 저품질 위험을 감수할 이유가 생긴다** — 그래도 계정을
   나눠(테스트용 별도 블로그) 먼저 검증한 뒤에만
3. **CEO가 위험을 알고도 진행을 지시한다** — 그때는 별도 계정으로 시작하고,
   본 계정에는 붙이지 않는다

**이건 CEO 결정 사항이다.** 기술적으로 막혀서 못 하는 게 아니라, 위험 대비
이득이 안 맞아서 안 하는 것이다. 판단이 바뀌면 알려주면 그때 붙인다.

---

## 5. 대안 — 자동화 없이 손을 더는 방법

- **예약 발행**: 네이버 에디터 자체 예약 기능. 3건을 한 번에 붙여넣고 시간대를
  나눠 예약하면 하루 한 번 작업으로 끝난다
- **모바일 앱 임시저장**: PC에서 붙여넣기 → 임시저장 → 이동 중 발행
- **이미지 사전 준비**: 매일 쓰는 이미지 유형(현장 사진·도표)을 미리 모아두면
  붙여넣기 시간이 크게 준다
